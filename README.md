# Manojkumar Gurram - Portfolio

Source for my personal portfolio website. The site introduces my background in security analysis and VAPT, selected projects, and research interests in explainable machine learning for threat detection.

## Run locally

This is a static website. Clone the repository and open `index.html` in a browser. The page loads Google Fonts from the web, so its typography may differ when offline.

## Contents

- `index.html` — portfolio content and layout
- CSS and JavaScript assets — styling and page interactions
